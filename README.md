# 📌 Bookmark Manager

Um aplicativo web para organizar e gerenciar seus links favoritos de forma eficiente.

## 🚀 Tecnologias Utilizadas

### Frontend Principal

| Tecnologia                                                                                                              | Descrição                                           |
| ----------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| ![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)                     | Biblioteca JavaScript para construção de interfaces |
| ![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=for-the-badge&logo=typescript&logoColor=white)       | Superset JavaScript com tipagem estática            |
| ![Zustand](https://img.shields.io/badge/-Zustand-764ABC?style=for-the-badge)                                            | Gerenciamento de estado simplificado                |
| ![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white) | Framework CSS utilitário                            |
